# Quirón OS Engineering Constitution

1. **Stack simplicity:** Use the approved stack defined in [architecture](architecture.md); document the need and obtain approval before adding a dependency or technology.
2. **Specification:** Trace implementation to an approved specification, plan, tasks, and measurable acceptance criteria.
3. **Boundaries:** Keep business logic separate from delivery, infrastructure, and AI providers; preserve domain ownership and approved cross-domain contracts.
4. **Verification:** Require behavior-focused tests, boundary checks, independent review, and passing CI before completion.
5. **Persistence:** Give each domain ownership of its data; review migrations and verify transactional consistency and reliable event delivery when those capabilities are implemented.
6. **Language:** Use English for code and technical artifacts; use Spanish by default for employee- and customer-facing communication.
